# DealNest Landing Page

A responsive, single-file landing page ready for GitHub Pages. No build tools, packages or backend needed.

## Publish on GitHub Pages

1. Create a public GitHub repository (e.g. `dealnest`).
2. Upload `index.html` to the repository root and commit.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Visit `https://YOUR-USERNAME.github.io/dealnest/` once deployment finishes.

## Before going live

- Replace `hello@example.com` in `index.html` with your actual business email.
- Replace the DealNest name if you want a different brand.
- Add real business contact details, accurate offers and approved affiliate links.
- Add privacy, terms and disclosures appropriate to your business before collecting customer data.
- This is a static landing page. Lead storage, admin login, CRM and automation are not included yet.
